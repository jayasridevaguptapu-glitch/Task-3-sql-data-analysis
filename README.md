Task 3: SQL for Data Analysis

Objective:
To analyze data using sql queries and perform operations such as filtering,sorting,grouping,joins,subqueries,aggregate function,views, and indexes.

Tools Used:
- MySQL Workbench

Dataset:
- Ecommerce Sample Database containing customer and order information.

Operations Performed:
1. SELECT queries
2. Filtering using WHERE
3. Sorting using ORDER BY
4. Aggregation using GROUP BY
5. INNER JOIN and LEFT JOIN
6. Subqueries
7. Aggregate functions (SUM, AVG)
8. Created a View for analysis
9. Created an Index for optimization

Outcome:
Learned how to retrieve, analyze, and optimize structured data using SQL.Gained practical experience in data querying,joins,aggregations,and database performance optimization.
